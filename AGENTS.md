# AGENTS

## Project

`ruby-rule-frus-quest` is a Vite + TypeScript + Phaser 3 game. It deploys as a static GitHub Pages site and as a Capacitor iPhone app built from the same `dist/` output.

## Commands

```bash
npm install
npm run dev
npm run build
npm run build:ios
npm run ios:open
```

## Conventions

- Keep StateChat as terminal or panel text only. Do not draw it as a face, mascot, body, or assistant character.
- Keep decisions human-centered. Only `mechanical` proposals may auto-apply.
- Preserve the NES-style 256x240 logical canvas.
- Use repository-local or locally generated assets only.
- Keep generated Web Audio tones original; do not import borrowed chiptunes or sound effects.
- Keep dialog short, crisp, and readable at 8-bit scale.
- Update `progress.md` after meaningful changes.
