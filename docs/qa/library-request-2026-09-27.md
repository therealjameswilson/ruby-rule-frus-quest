# Reagan Library request desk

The first finding-aid station now asks the player to build a request slip from catalog metadata. This optional example does not assign a FRUS volume. Later comparison, source-note, and filing stations remain in place.

Source: [Reagan Library VIP Visits finding aid](https://www.reaganlibrary.gov/sites/default/files/finding_aids_pdfs/219646.pdf), inspected September 27, 2026. RAC Box 6 starts on PDF page 12; the December 1984 Thatcher and January 1985 Buthelezi entries appear on page 13, and the February 1985 Thatcher entry appears on page 14. The selected Thatcher entry is OPEN without a DIGITIZED marker. The interaction presents metadata, not invented document contents. Access and retrieval still need confirmation.

The player must select the matching visitor/date, attach the exact locator, distinguish an open lead from documents reviewed online, and carry forward retrieval and withdrawal checks. Changing entries invalidates the old locator and access assessment. Drafts persist without granting completed research. Submission advances only the first station; it does not mark documents retrieved or a volume complete.

Model tests cover complete/incomplete requests, access overstatement, changed-entry invalidation, malformed selection, and draft serialization. Shared DeskControls provides native-resolution layout, keyboard/controller navigation, reading audio attenuation, and modal cleanup. Library fullscreen handling now runs before dialogue/choice branches so the desk can enter fullscreen.

Build and 278 test files / 2,088 tests passed. Browser outcomes and limitations are recorded separately in library-request-2026-09-27.json. This is local work, not a public release.
