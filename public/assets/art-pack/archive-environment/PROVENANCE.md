# NARA environment artwork

`props-v2.png` is original artwork generated for Ruby Rule on 2026-09-24 with OpenAI image generation. A second generation pass adapted the low shelving and pallet silhouettes for the high-angle game camera. The generated 2172x724 RGBA source and its alpha are preserved unchanged.

The atlas contains paper-box shelving, mixed book/box shelving (including ruby-red volumes), and cartons on a low pallet. Runtime source rectangles use alpha bounds; destination rectangles come directly from the NaraStacksScene collision geometry. Canvas-generated terrazzo, limestone, lighting and steps are original code-native environment art, baked once at 3x resolution. No external game assets are used.
