Audio playback is generated in code by `src/systems/audio.ts` so the game works reliably on GitHub Pages without browser MIDI plugins.

The checked-in `.mid` files in `midi/` are public-domain source clips used as the basis for short square-wave in-game motifs. See `ATTRIBUTION.md` for source URLs and rights notes.

Future music and sound effects must be original, public-domain, or otherwise explicitly cleared for repository-local use and GitHub Pages deployment.
